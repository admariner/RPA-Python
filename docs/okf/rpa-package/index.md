# rpa-package

Concepts for `rpa_package/`, the source of the `rpa` PyPI distribution
(the package name used in this project's own documentation and samples,
`import rpa as r`).

* [rpa](rpa.md) - re-exports `tagui.py`'s public API under the `rpa`
  module name.
* [setup](setup.md) - `setuptools` packaging script for the `rpa`
  distribution.
